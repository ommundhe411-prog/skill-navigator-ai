# Skill Navigator AI

Role: Act as a Senior Software Engineer and AI Product Architect with 20+ years of experience building scalable EdTech, AI-powered learning platforms, and modern enterprise web applications.

Goal: I want to build an AI-Powered Skill Bridge platform that identifies the gap between a user's current skills and their target career/job role, then creates a personalized learning and career roadmap to help them become job-ready.

Specification:
Build the website using Vanilla JavaScript, HTML, and Tailwind CSS. Do not use React, Vue, Angular, or any other frontend framework.

The website should have a premium, modern, intelligent, and highly polished UI/UX inspired by modern platforms such as LinkedIn Learning, Coursera, Udemy, and modern AI dashboards, but the design must be completely original and should not directly copy their branding, layouts, logos, or exact UI.
